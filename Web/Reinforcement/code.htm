Pseudo code example

The following C++ pseudo code section implements the heart of a simple feed-forward neural network. All used reinforcement learners are derived from this object, the corresponding code examples can be found here.

class Perceptron 
{ 
  int m_I;                      Number of input units 
  int m_H;                      Number of hidden units 
  float m_x[m_I];               The input vector of dimension m_I 
  float m_y[m_H];               The hidden vector of dimension m_H 
  float m_z;                    The output unit 
  float m_rih[m_I][m_H];        The weight matrix from input to hidden layer 
  float m_rho[m_H];             The weight vector from hidden to output layer 
  
  void propagate () 
  { 
    Propagate the input vector m_x through the net 
    Input: m_x, m_I, m_H, m_rih, m_rho 
    Output: m_y, m_z 
  
    Calculate the activation levels of the hidden layer 
    for (h = 0; h < m_H; h++) 
    { 
      m_y[h] = 0.0;             Sum up inputs * weights 
      for (i = 0; i < m_I; i++) m_y[h] += m_rih[i][h] * m_x[i]; 
      Apply sigmoid function to hidden unit 
      m_y[h] = sigma(m_y[h]); 
    } 
  
    m_z = 0.0;                  Calculate the activation level of the output unit 
    for (h = 0; h < m_H; h++) m_z += m_rho[h] * m_y[h]; 
  } 
};
