Reinforcement learning

A neural network learns to play Abalone

We now present a brief summary of the implemented reinforcement learning system (see Tesauro [Tes95]). The heart of the reinforcement learner is a neural network that is organized as a standard multilayer perceptron (MLP), see Section 1.1. The training procedure is as follows: the network observes a sequence of board positions j0 , j1 , ... , jN , starting with the opening position j0 and ending in a terminal position jN characterized by the score, i.e. 6 : 3 or 5 : 6. The board positions are fed as input vectors x(j0), x(j1), ... , x(jN) to the neural network, encoded using a representation scheme x(·) that is described later. Each time step in the sequence corresponds to a move made by one side, i.e. a half-move or a ply. For each input position jk there is a neural network output J(jk,r), where r is the network's weight vector. J(jk,r) is the neural networks estimate of the value of the position jk . The quantity lambda is a heuristic parameter controlling the temporal credit assignment of how an error detected at a given time step feeds back to correct previous estimates. When lambda = 0, no feedback occurs beyond the current time step, while when lambda = 1, the error feeds back without decay arbitrarily far in time. Intermediate values of lambda provide a smooth way to interpolate between these two limiting cases.

At the end of each game, a final reward signal J*(jN+1) is given, based on the outcome of the game. The preceding equation is used to change the weights, except that the difference (J*(jN+1)  - J(jN,rN)) is used instead of (J(jN+1,rN)   - J(jN,rN)).

During training, the neural network itself is used to select moves for both sides. At each time step during the course of a game, the neural network scores every possible legal move. The move that is selected is then the move with maximum expected outcome for the side making the move. In other words, the neural network is learning from the results of playing against itself. This self-play training paradigm is used even at the start of learning, when the network's weights are random, and hence its initial strategy is a random strategy.
