Malin is an Abalone playing computer program running on Microsoft Windows platforms. It is primarily designed as a testbed for different game-playing algorithms (including neural networks) and not as a commercial program. Nevertheless the program features a graphical user interface which makes it fairly easy to use.

By the way, the name Malin is derived from the French adjective malin, which could be translated to English by clever, bright, astute and to German by schlau, or gewitzt.
