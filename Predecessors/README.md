# Predecessors

Earlier DOS versions of Abalone (Turbo C / Assembler, EGA/VGA graphics via BGI), written before the reinforcement-learning thesis of 1998/99.

| Folder | Content |
|---|---|
| `Aba1` | First version |
| `Dez95_TCABA` | Backup from December 1995: Aba2 versions 201–207 and AI parameter files (`.AP`, `.AG`, `.AI`) |
| `Aba207` | Version 207 with AI parameter files |
| `Juli98_Aba208` | Version 208, July 1998 |
| `Aba209` – `Aba213` | Later 1998 versions |
| `Utilities` | Mouse cursor files (`.LMC`) and assembler helper `ABAUTLA.ASM` |

Built with Borland Turbo C (`.PRJ`); `EGAVGA.BGI` is included. Object files, maps and backups were left out. Umlauts in the sources may use the DOS code page (CP850).
